## 1. Editorial Strategy: The Forensic Data Moat

Web Audits does not publish generic "SEO + AI + hosting + web design" listicles. We operate as an **authoritative digital publication and engineering intelligence lab**.

### The 3 Rules of Forensic Publishing:
1. **Never make a claim without showing the telemetry**: Every guide, benchmark, or autopsy requires an instrumented Evidence Box (`whatWeTested`, `observedResult`, `source`).
2. **The Repeatable Teardown Protocol**: Every teardown and autopsy strictly follows the 5-stage formula:  
   `What we tested -> Evidence -> What caused it -> What to change -> Before/after`
3. **No Unearned Guru Hype**: We never promise "instant rankings" or "4x citation guarantees". We report measured observations, sample statistics, and reproducible test configurations.

## 4. Operational Invariants & Quality SOP

Every piece of content must strictly adhere to the following 5 rules before merging:
1. **Zero Em-Dashes or En-Dashes**: Strictly enforce hyphens and colons only.
2. **Mandatory Evidence Box**: State `whatWeTested`, `observedResult`, and `source` explicitly.
3. **No Guru Guarantees**: Use observational language ("correlated with", "observed in our sample").
4. **FTC Compliance**: Outbound commercial links must enforce `rel="nofollow sponsored noopener"`.
5. **SRE Build Verification**: `npm run build` passes with 0 errors and 0 horizontal layout overflow.
